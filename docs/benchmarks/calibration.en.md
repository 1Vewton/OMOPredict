# Model calibration report (M2.3)

> **English** · [中文版](calibration.md)

> Data: the three literature datasets in `docs/benchmarks/` (Voronin 2025 / Isiyaku 2020 / Lim 2020).
> Reproduction: `omo.benchmark.calibrate` (sensitivity analysis → L-BFGS-B fitting → held-out validation).

## Method

- **Loss**: quantity-weighted MSE — Rs in log₁₀ space (weight 1), T/R absolute values (weight 1), SE in dB (weight 0.1).
- **Training/validation split**: training = Voronin IAI-3 + Isiyaku + WAW 0.50/0.75/1.00;
  validation (held out) = Voronin IAI-1/IAI-2 (thin Ag 7.3/10.1 nm) + WAW 0.25.
- **Fitting**: scipy `L-BFGS-B`, with physically reasonable ranges as the bounds.

## Sensitivity analysis (training set, normalized loss change)

| Constant | Sensitivity | Interpretation |
|---|---|---|
| Ag bulk resistivity ρ | 0.224 | the dominant parameter for Rs |
| Ag mean free path λ | 0.125 | strength of the size effect (sensitive for thin Ag) |
| ITO refractive index n | 0.016 | affects the Isiyaku transmittance |
| WO₃₋ₓ refractive index n | 0.0005 | WAW optics already agree; not sensitive |
| Ag Drude damping γ | ≈0 | negligible effect on this batch of observables |

The calibration targets are the three with a sensitivity peak >3%: **Ag ρ, Ag λ, ITO n**.

## Fitting results

| Constant | Default value | Fitted value | Bounds |
|---|---|---|---|
| Ag ρ (Ω·m) | 1.59e-8 | **2.60e-8 (hits the upper bound)** | [1.2e-8, 2.6e-8] |
| Ag λ (nm) | 52 | **95** | [20, 150] |
| ITO n | 1.8 | **2.1 (hits the upper bound)** | [1.6, 2.1] |

## Error change (weighted loss / per-quantity MAE)

| Subset | Before calibration | After calibration |
|---|---|---|
| Training loss | 7.75 | **0.59** (↓92%) |
| Validation loss | 0.374 | **0.183** (Rs log₁₀ MAE, ↓51%) |

## Scientific interpretation (important)

1. **Ag ρ and λ are both revised upward**: the fit requires the "effective resistivity" to be significantly higher than the bulk value (1.59e-8 → 2.6e-8+),
   reflecting that **interface/grain-boundary scattering** makes the actual conductivity of the film worse than the FS model assumes. These two parameters should be treated as
   **effective model parameters** (used only for simulation prediction), and **must not rewrite the physical bulk values** (the CRC values are still the true values).
   Hitting the bound suggests that the upper bound for ρ could be relaxed or an interface-scattering term introduced (beyond the scope of M2, recorded as a model improvement direction).
2. **ITO n moves up** (1.8 → 2.1), improving the Isiyaku transmittance benchmarking — sputtered ITO refractive indices do
   have a process-dependent range of 1.8–2.1, and the fitted value is within the physical range.
3. **The validation-set error (held-out thin Ag 7.3/10.1 nm) halves but is still significant**: the percolation/nucleation
   (island growth) effect of thin Ag is beyond the Fuchs–Sondheimer continuous-film assumption — this is a **model boundary**,
   not a constants problem, and it is not force-fitted (consistent with the calibration discipline in AGENTS.md).
4. **The WO₃₋ₓ system matches well** (before calibration Rs 7%, T 3.6%) → this system can serve as a benchmark
   for the credibility of the default parameters.

## How to use

The fitted values are used in the form of a **dataset simulation override section** (generated by
`build_overrides` in `calibrate.py`) and are not written into the engine registry; if the default values need to be updated, that requires review
(the AGENTS.md §6 discipline). The generated `calibration_report.json` is a derived artefact (gitignore).
