# Literature benchmarking datasets (docs/benchmarks/)

> **English** · [中文版](README.md)

Each JSON file corresponds to the measured data of one paper (or several papers on the same system). Naming: `system_authoryear.json`.

## Schema overview

```json
{
  "meta": {
    "id": "unique identifier (filename style)",
    "paper": { "title": "...", "authors": "...", "year": 2020, "doi": "10.xxxx/yyyy", "journal": "..." },
    "substrate": { "material": "glass", "index": 1.5 },
    "extraction": { "method": "table | figure-digitized", "note": "extraction conditions" }
  },
  "records": [
    {
      "id": "s1",
      "stack": [{ "material": "ITO", "thickness_nm": 40.0 }, { "material": "Ag", "thickness_nm": 10.0 }],
      "measured": {
        "transmittance": [{ "wavelength_nm": 550.0, "value": 0.87 }],
        "reflectance":  [{ "wavelength_nm": 550.0, "value": 0.05 }],
        "sheet_resistance": 6.5,
        "se": [{ "frequency_ghz": 10.0, "value": 28.0 }],
        "se_x_band": 28.0
      }
    }
  ],
  "simulation": {
    "materials": {
      "ITO": { "optics": { "constant_index": [1.82, 0.0] }, "electrical": { "bulk_resistivity": 1.2e-6 } },
      "Ag":  { "optics": { "drude": { "eps_inf": 3.7, "plasma_energy_ev": 9.1, "damping_energy_ev": 0.03 } },
               "electrical": { "mean_free_path_nm": 55.0 } }
    }
  }
}
```

## Conventions

- `measured` may be any subset (items may be absent): a record with only Rs does not trigger optical/shielding simulation
- Transmittance/reflectance are **fractions** (0–1); Rs is in Ω/sq; SE is in dB
- `simulation.materials` is optional: it overrides the engine's default material constants (**an M2.3 calibration artefact**);
  the optics override is one of two forms: `constant_index` (an [n, k] array) or `drude` (the full parameters)
- Material names correspond to the `omo.benchmark.materials.MaterialResolver` registry (ITO / Ag / glass),
  and new materials must be provided in the registry or in an override section

## Model calibration (M2.3)

For the method, results and interpretation see **`calibration.md`**. Key points:
- sensitivity analysis → fit the most sensitive constants (Ag ρ / λ, ITO n) → held-out validation
- the calibration artefact is **effective model parameters** (an override section); it does not rewrite the physical bulk values
- the percolation effect of thin Ag is beyond the FS model — marked as a model boundary and not force-fitted
