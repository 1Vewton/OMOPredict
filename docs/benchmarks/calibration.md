# 模型校准报告（M2.3）

> 数据：`docs/benchmarks/` 三篇文献数据集（Voronin 2025 / Isiyaku 2020 / Lim 2020）。
> 复现：`omo.benchmark.calibrate`（灵敏度分析 → L-BFGS-B 拟合 → 留出法验证）。

## 方法

- **损失**：按量加权 MSE——Rs 取 log₁₀ 空间（权重 1）、T/R 绝对值（权重 1）、SE dB（权重 0.1）。
- **训练/验证划分**：训练 = Voronin IAI-3 + Isiyaku + WAW 0.50/0.75/1.00；
  验证（留出）= Voronin IAI-1/IAI-2（薄 Ag 7.3/10.1 nm）+ WAW 0.25。
- **拟合**：scipy `L-BFGS-B`，边界为物理合理范围。

## 灵敏度分析（训练集，归一化损失变化）

| 常数 | 灵敏度 | 解读 |
|---|---|---|
| Ag 块体电阻率 ρ | 0.224 | Rs 主导参数 |
| Ag 平均自由程 λ | 0.125 | 尺寸效应强度（薄 Ag 敏感） |
| ITO 折射率 n | 0.016 | 影响 Isiyaku 透过率 |
| WO₃₋ₓ 折射率 n | 0.0005 | WAW 光学已吻合，不敏感 |
| Ag Drude 阻尼 γ | ≈0 | 对本批观测量的影响可忽略 |

校准对象取灵敏度峰值 >3% 的三个：**Ag ρ、Ag λ、ITO n**。

## 拟合结果

| 常数 | 默认值 | 拟合值 | 边界 |
|---|---|---|---|
| Ag ρ（Ω·m） | 1.59e-8 | **2.60e-8（触上界）** | [1.2e-8, 2.6e-8] |
| Ag λ（nm） | 52 | **95** | [20, 150] |
| ITO n | 1.8 | **2.1（触上界）** | [1.6, 2.1] |

## 误差变化（加权损失 / 逐量 MAE）

| 子集 | 校准前 | 校准后 |
|---|---|---|
| 训练损失 | 7.75 | **0.59**（↓92%） |
| 验证损失 | 0.374 | **0.183**（Rs log₁₀ MAE，↓51%） |

## 科学解读（重要）

1. **Ag ρ 与 λ 同时上调**：拟合要求"有效电阻率"显著高于块体值（1.59e-8 → 2.6e-8+），
   反映**界面/晶界散射**使薄膜实际导电性劣于 FS 模型假设。这两个参数应视为
   **模型有效参数**（仅用于仿真预测），**不应改写物理块体值**（CRC 值仍为真值）。
   边界触顶提示可放宽 ρ 上界或引入界面散射项（超出 M2 范围，记为模型改进方向）。
2. **ITO n 上移**（1.8 → 2.1）改善 Isiyaku 透过率对标——溅射 ITO 折射率确实
   存在 1.8–2.1 的工艺依赖区间，拟合值在物理范围内。
3. **验证集（留出的薄 Ag 7.3/10.1 nm）误差减半但仍显著**：薄 Ag 的渗流/成核
   （island growth）效应超出 Fuchs–Sondheimer 连续膜假设——这是**模型边界**，
   不是常数问题，不强行拟合（符合 AGENTS.md 校准纪律）。
4. **WO₃₋ₓ 体系吻合良好**（校准前 Rs 7%、T 3.6%）→ 该体系可作为默认参数
   可信度的基准。

## 使用方式

拟合值以**数据集 simulation 覆盖段**形式使用（`calibrate.py` 的
`build_overrides` 生成），不写入引擎注册表；如需更新默认值，须经评审
（AGENTS.md §6 纪律）。生成的 `calibration_report.json` 为派生产物（gitignore）。
