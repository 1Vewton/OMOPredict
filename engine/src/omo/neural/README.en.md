# omo.neural —— neural-network surrogate model (M2.5 implemented, v1)

> **English** · [中文版](README.md)

## Responsibility

Use an NN to approximate the physics engine's "structural parameters → performance" mapping, as a **simulation accelerator and optimization surrogate**:

- Forward surrogate: input three layer thicknesses → output the T(λ) spectrum, Rs, SE(f) curve
- **The physics engine remains the sole validation baseline, the NN does not replace the physics engine** (AGENTS.md §3.6)

## Implemented modules

| Module | Responsibility |
|---|---|
| `data.py` | Engine-generated data: `generate_dataset` / `SurrogateConfig` / `SurrogateDataset` (fixed seed, 20% boundary samples, pipeline versioning) |
| `model.py` | `SurrogateModel`: MLP (3 → hidden → 82 outputs), z-score normalization, early stopping, `train/predict/save/load` |
| `validate.py` | `validate`: independent test set (different seed) compared with the engine → `SurrogateValidationReport` (MAE/RMSE of T/Rs/SE + training-domain boundary) |

## How to call it

```python
from omo.neural import SurrogateConfig, SurrogateDataset, SurrogateModel, generate_dataset, validate
from omo.neural.data import PIPELINE_VERSION

# 1. Engine generates data (20k samples by default; train/test use different seeds to prevent leakage)
train = generate_dataset(SurrogateConfig(n_samples=20_000, seed=42))
test = generate_dataset(SurrogateConfig(n_samples=2_000, seed=7))

# 2. Training (fixed seed, reproducible)
model = SurrogateModel(train.config)
model.train(train)                    # -> {"val_loss_best": ..., "epochs_run": ...}

# 3. Prediction (denormalized back to physical units)
pred = model.predict([[40.0, 10.0, 40.0]])   # ITO(40)/Ag(10)/ITO(40)
pred.transmittance      # (1, 63) wavelengths 380–1000 nm
pred.sheet_resistance   # (1,) Ω/sq
pred.se_db              # (1, 18) frequencies 1–18 GHz

# 4. Validation (engine as baseline) + extrapolation risk
report = validate(model, test)
report.save_json("surrogate_report.json")

# 5. Persistence (the deliverable includes config/pipeline version, not a black box)
model.save("surrogate.pt")
loaded = SurrogateModel.load("surrogate.pt")
```

## Data rules (AGENTS.md §6.9)

- Training data is always generated by the physics engine and versioned (`PIPELINE_VERSION` + fixed seed); literature measurements are used only for post-hoc calibration
- Sampling covers the parameter-space boundary (20% boundary samples including corner points); train/test use different seeds
- Rs is trained in log₁₀; spectra/SE use fixed-grid vector regression
- Predictions outside the training domain (oxide 20–80 nm, metal 5–20 nm) are **extrapolation**, with no accuracy guarantee (the report includes the training domain)

## Measured results (20k training / 3k independent test, engine as baseline)

| Metric | Value |
|---|---|
| T(λ) MAE / RMSE | 0.0009 / 0.0011 |
| Rs relative error | 0.2% (log₁₀ MAE 0.0009) |
| SE MAE / RMSE | 0.02 / 0.02 dB |

Reproduction: `cd engine && uv run python scripts/train_surrogate.py`
(artefacts: `artifacts/surrogate_ito_ag_ito.pt`, `docs/benchmarks/surrogate_report.json`, both gitignored).

## v1 scope and extensions

- v1: ITO/Ag/ITO three layers, input three thicknesses, fixed materials (ITO n=1.8, Ag Drude, glass substrate)
- Extension route: material parameters (n/ρ/γ) as features, more systems, inverse design (target performance → thickness)
